# Legacy v1

This folder holds the original Rocket Carousel Maker: HTML carousels written by hand from the PNG templates, with an html2canvas download button injected by `inject_download.ps1`. It is here for reference only and is no longer maintained.

| Path | What it was |
|---|---|
| `carousel_sop.md` | v1 SOP (direct HTML generation, templates as ground truth) |
| `carousel maker skill..md` | v1 Claude skill |
| `design-skills/` | Third-party design skill files that v1 used as references. Each one keeps its original authors' terms. |
| `templates/`, `assets/` | PNG reference templates and background images |
| `carousels/` | Example carousels built with v1 |
| `inject_download.ps1` | Adds the html2canvas "Download 4K" button to HTML files |

For new work, use the v2 system described in the repository [README](../../README.md).
